# Testar a API do LUME no Insomnia

A coleção oficial agora está na pasta exclusiva **[`/insomnia`](../insomnia/)**, na raiz do projeto.

- **[Importar a coleção — `insomnia/colecao-lume.json`](../insomnia/colecao-lume.json)**.
- **[Guia para o grupo: instalação, variáveis, oito endpoints e segurança](../insomnia/README.md)**.
- URL-base: `http://localhost:3333`, **sem prefixo `/api`**.

Os JWTs e as senhas são fornecidos **apenas no Insomnia local**. A coleção versionada não inclui credenciais reais e não deve ser exportada de volta ao GitHub depois de receber dados privados.

A coleção antiga com 67 requisições se referia a outro contrato de API. A coleção atual possui **somente as 8 operações realmente implementadas** no backend da `dev`.
